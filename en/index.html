Austria · official data

The map of Austria, built from official data.

Parcels, addresses, routing, terrain, orthophoto, public transport, traffic reports and weather – from the cadastral map, laser scan, road graph and timetable of the authorities, as open tiles and APIs for your own maps.

What mapx delivers

Each product is its own dataset with a reference date and source. Each product has its own page with an example, the data source and limitations. Everything you see on the map can also be embedded directly.

Maps, tiles and styles

Vector basemap, ready-made map styles, contours and orthophoto as vector and raster tiles for MapLibre. · PMTiles · TileJSON

Cadastre and parcels

Parcel boundaries as tiles, the parcel at a point and a parcel dossier, from the BEV digital cadastral map. · BEV DKM · CC BY 4.0

Geocoding and address search

Address register, places, streets and parcels: geocoding, reverse geocoding, type-ahead search, autofill and address validation. · Address register, as of 01.10.2026

Routing

Routes for car, truck, bike and foot, isochrones, travel-time matrices and tour planning on the GIP road graph. · GIP.at · CC BY 4.0

Elevation and terrain

Elevation API for points and profiles, terrain model (DTM) and surface model (DSM) at 1 m resolution, contour lines. · BEV · reference date 15.09.2025

Public transport

Journeys, stops and departures from the scheduled timetable, reachability by public transport as an isochrone. · ÖBB-Personenverkehr AG · CC BY 4.0

Traffic

Traffic reports, roadworks and closures, speed limits on variable message signs on motorways and a traffic layer for the map. · ASFINAG / EVIS.AT · CC BY 4.0

Static map images

A map as PNG or WebP with pins, paths and GeoJSON, for reports, e-mails and property listings. · up to 1280 × 1280 pixels

Weather and climate

Observations, hourly forecast, precipitation nowcast, warnings, air quality and climate for a point. · GeoSphere Austria · CC BY 4.0

MCP server for AI assistants

23 read-only tools for addresses, routes, parcels, weather and more, directly in Claude Code, Cursor and VS Code. · MCP · Streamable HTTP

Embed it in five minutes.

For developers – Tiles are PMTiles files with HTTP range access, no map server of your own needed. The APIs answer with JSON or GeoJSON.

  • MapLibre and PMTiles. Ready-made map styles come from the maps API (/v1/styles).
  • A free account is all you need. Sign in, create a token, get going. Origin, reference date and attribution are listed per product in the docs.
  • Machine-readable. OpenAPI description and llms.txt for all APIs and the tiles.

Map with MapLibre

import maplibregl from 'maplibre-gl';
import { Protocol } from 'pmtiles';

const TOKEN = 'YOUR_TOKEN'; // public token mx_pk_… from your account
maplibregl.addProtocol('pmtiles', new Protocol().tile);

const map = new maplibregl.Map({
  container: 'map',
  style: 'https://api.mapx.at/v1/styles/streets',
  // appends the token to every request to mapx.at (style, tiles, fonts, sprites)
  transformRequest: (url) => ({ url: /^https:\/\/([\w-]+\.)?mapx\.at\//.test(url)
    ? url + (url.includes('?') ? '&' : '?') + 'access_token=' + TOKEN : url }),
  center: [15.33, 48.23],
  zoom: 13
});

Query elevation

// Summit elevation from the terrain model (DTM, 1 m); token from your account
const r = await fetch(
  'https://api.mapx.at/v1/elevation?points=12.694,47.074',
  { headers: { Authorization: `Bearer ${TOKEN}` } }
);
const { features } = await r.json();
console.log(features[0].properties.elevation);

Free, with your own account.

API access – The mapx APIs (tiles, search, routing, elevation, transit, traffic, images, weather) require an account with an API token as of 8 November 2026. It costs nothing: sign up, sign in, create a token.

1. Sign up

With your email address. Sign-in uses an 8-digit code we send you by email. There is no password.

2. Create tokens

As many as you like, each with its own name. Block, renew or delete them at any time.

3. See your usage

For every token you can see usage per product and day. Nothing is billed.

Two kinds of tokens

  • Public token (mx_pk_…). For websites and apps. It is read-only and bound to your domains or your Android app, so nobody else can use it.
  • Secret token (mx_sk_…). For your server or scripts. Never put it in a web page or an app.

To protect against abuse there are rate limits per token. Usage itself is free of charge.

A source you can name.

Why official data – mapx builds maps exclusively from data of public authorities under a clear open licence. Every dataset is documented with publisher, reference date and licence.

  • Cadastre, terrain, orthophoto: Federal Office of Metrology and Surveying (BEV).
  • Roads, rail, routing: Graph Integration Platform GIP.at.
  • Water: national water network of the Umweltbundesamt.
  • Timetable: ÖBB-Personenverkehr AG, data source Mobilitätsverbünde Österreich OG.
  • Traffic reports: ASFINAG / EVIS.AT.
  • Weather, climate, air quality: GeoSphere Austria.
  • No OpenStreetMap: points of interest also come from official sources.
