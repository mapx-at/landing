For developers

Your first map in five minutes

A style URL and your token are all MapLibre needs. All other APIs answer with JSON or GeoJSON.

Map with MapLibre
import maplibregl from 'maplibre-gl';
import { Protocol } from 'pmtiles';

const TOKEN = 'YOUR_TOKEN'; // public token mx_pk_… from your account
maplibregl.addProtocol('pmtiles', new Protocol().tile);

const map = new maplibregl.Map({
  container: 'map',
  style: 'https://api.mapx.at/v1/styles/light',
  // adds the token to every request to mapx.at
  transformRequest: (url) => ({ url: /^https:\/\/([\w-]+\.)?mapx\.at\//.test(url)
    ? url + (url.includes('?') ? '&' : '?') + 'access_token=' + TOKEN : url }),
  center: [13.0455, 47.799],
  zoom: 14.2
});
Second example: query an elevation
// summit height from the terrain model (DTM, 1 m)
const r = await fetch(
  'https://api.mapx.at/v1/elevation?points=12.694,47.074',
  { headers: { Authorization: `Bearer ${TOKEN}` } }
);
const { features } = await r.json();
console.log(features[0].properties.elevation);

Access

Free, with your own account and token

The APIs need an account with a token. It costs nothing; rate limits per token protect against abuse.

  1. 1Sign inWith your e-mail address and a code we send you. There is no password.
  2. 2Create a tokenAs many as you need, and you can block, renew or delete them at any time.
  3. 3See your usagePer token and product, day by day. Nothing is billed.
mx_pk_… Public token
For websites and apps. Read-only, bound to your domains or your Android app.
mx_sk_… Secret token
For your server and scripts, never in a website or app.
