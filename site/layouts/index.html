Für Entwickler

Einbinden in fünf Minuten.

Kacheln sind PMTiles-Dateien mit HTTP-Range-Zugriff, ohne eigenen Kartenserver. Die Höhen-API antwortet mit GeoJSON.

  • MapLibre und PMTiles. Der Stil der Demo-Karte ist öffentlich und lässt sich direkt laden.
  • Keine Schlüssel für offene Daten. Herkunft, Stichtag und Attribution stehen je Produkt in der Doku.
  • Maschinenlesbar. OpenAPI-Beschreibung und llms.txt für die Höhen-API und die Kacheln.

Karte mit MapLibre
import maplibregl from 'maplibre-gl';
import { Protocol } from 'pmtiles';

maplibregl.addProtocol('pmtiles', new Protocol().tile);

const map = new maplibregl.Map({
  container: 'map',
  style: 'https://mapx.at/style.json',
  center: [15.33, 48.23],
  zoom: 13
});
Höhe abfragen
// Gipfelhöhe aus dem Geländemodell (DTM, 1 m)
const r = await fetch(
  'https://api.mapx.at/v1/elevation?points=12.694,47.074'
);
const { features } = await r.json();
console.log(features[0].properties.elevation);
Warum amtliche Daten

Eine Quelle, die man benennen kann.

mapx baut Karten ausschließlich aus Daten von Behörden mit klarer offener Lizenz. Jeder Datensatz ist mit Herausgeber, Stichtag und Lizenz dokumentiert.

  • Kataster, Gelände, Orthofoto: Bundesamt für Eich- und Vermessungswesen (BEV).
  • Straßen, Bahn, Routing: Graphenintegrations-Plattform GIP.at.
  • Gewässer: Gesamtgewässernetz des Umweltbundesamts.
  • Kein OpenStreetMap: Punkte von Interesse kommen ebenfalls aus amtlichen Quellen.
