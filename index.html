Für Entwickler

Deine erste Karte in fünf Minuten

Für eine Karte mit MapLibre genügen ein Stil-Link und dein Token. Alle anderen APIs antworten mit JSON oder GeoJSON.

Karte mit MapLibre
import maplibregl from 'maplibre-gl';
import { Protocol } from 'pmtiles';

const TOKEN = 'YOUR_TOKEN'; // öffentlicher Token mx_pk_… vom Konto
maplibregl.addProtocol('pmtiles', new Protocol().tile);

const map = new maplibregl.Map({
  container: 'map',
  style: 'https://api.mapx.at/v1/styles/light',
  // hängt den Token an jede Anfrage an mapx.at
  transformRequest: (url) => ({ url: /^https:\/\/([\w-]+\.)?mapx\.at\//.test(url)
    ? url + (url.includes('?') ? '&' : '?') + 'access_token=' + TOKEN : url }),
  center: [13.0455, 47.799],
  zoom: 14.2
});
Zweites Beispiel: Höhe abfragen
// Gipfelhöhe aus dem Geländemodell (DTM, 1 m)
const r = await fetch(
  'https://api.mapx.at/v1/elevation?points=12.694,47.074',
  { headers: { Authorization: `Bearer ${TOKEN}` } }
);
const { features } = await r.json();
console.log(features[0].properties.elevation);

Zugang

Kostenlos, mit eigenem Konto und Token

Die APIs brauchen ein Konto mit Token. Das kostet nichts, zum Schutz vor Missbrauch gibt es Rate-Limits je Token.

  1. 1AnmeldenMit deiner E-Mail-Adresse und einem Code, den wir dir schicken. Ein Passwort gibt es nicht.
  2. 2Token anlegenSo viele du brauchst, jederzeit sperren, erneuern oder löschen.
  3. 3Nutzung einsehenJe Token und Produkt pro Tag. Abgerechnet wird nichts.
mx_pk_… Öffentlicher Token
Für Webseiten und Apps. Darf nur lesen, gebunden an deine Domains oder deine Android-App.
mx_sk_… Geheimer Token
Für deinen Server und Skripte, nie in eine Webseite oder App.
